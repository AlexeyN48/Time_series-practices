03

Разведочный анализ (EDA)

В ходе анализа выявлены следующие ключевые особенности временного ряда:

Сезонность

Ярко выраженная годовая аддитивная сезонность. Пики температуры приходятся на май–июнь (~35°C), минимумы — на декабрь–январь (~12°C). Амплитуда сезонных колебаний составляет ~23°C.

Тренд

Наблюдается слабый положительный линейный тренд — среднегодовое повышение температуры. Значимость тренда подтверждается при анализе остатков после сезонной декомпозиции.

Стационарность

Ряд является нестационарным: тест Дики–Фуллера (ADF) даёт статистику = −2.44, p-value = 0.131 — нулевая гипотеза не отвергается. После взятия 1-й разности: p-value ≈ 0.000 → ряд становится стационарным.

Корреляция

Выявлена сильная обратная корреляция между температурой и влажностью (r ≈ −0.57). Атмосферное давление также коррелирует с температурой, что подтверждает целесообразность мультивариатного подхода.

Анализ ACF / PACF

На дифференцированном ряду: ACF обрезается после лага 1–2 (q = 2), PACF обрезается после лага 1–2 (p = 2). Сезонный период 365 дней подтверждён спектральным анализом, однако для SARIMA использован недельный период (7) ввиду вычислительных ограничений.

04

Анализ аномалий

Выявление аномалий проведено тремя принципиально различными методами. Все применялись к обучающей выборке до обучения прогностических моделей.

4.1 Метод IQR Статистический

Принцип: Точка считается аномалией, если выходит за пределы [Q1 − 1.5·IQR, Q3 + 1.5·IQR].

Обоснование: Непараметрический, не требует обучения. Границы: нижняя ≈ 5.4°C, верхняя ≈ 37.7°C.

Результат: Обнаружено 8 аномалий — экстремально холодные дни зимой (t < 5°C).

Дополнительно обнаружена критическая аномалия в meanpressure: значения ~59 ед. при норме ~1000 (сбой датчика). Аномальные значения заменены медианой.

4.2 Isolation Forest ML, ансамбль

Принцип: Аномальные точки изолируются быстрее (короче путь в дереве).

ПараметрЗначениеОбоснование
contamination0.03~3% аномалий по EDA
n_estimators200Стабильность на 1500 набл.
random_state42Воспроизводимость

Признаки: y, lag_1, lag_7, lag_30, rolling_mean_7 (стандартизированные).

Результат: 44 аномалии (~3%) — включая локальные отклонения, невидимые по абсолютному значению.

4.3 DBSCAN ML, кластеризация

Принцип: Кластеризация по плотности; точки вне плотных кластеров — аномалии.

ПараметрЗначениеОбоснование
eps1.5«Колено» k-distance графика (k=5)
min_samples5Минимальный размер плотного кластера

Признаки: y, rolling_mean_14, deviation, lag_1 (стандартизированные).

Результат: 23 аномалии, 4 кластера. Эффективен в переходные периоды (весна/осень).

5.7 Ключевые выводы

ML-подход выигрывает благодаря явной инженерии признаков: сезонность кодируется через lag_365 и dayofyear.

DL-подходы (NHITS, NBEATS) конкурентоспособны и не требуют ручного Feature Engineering — преимущество при работе с новыми рядами.

Статистические методы (MSTL, SeasonalNaive) — сильные конкуренты для структурированных сезонных рядов при малом объёме данных.

Финальная модель: LightGBM (MAE = 1.459°C, RMSE = 1.745°C).

06

Пайплайн решения задачи ВР

Реализован как единый объект sklearn.Pipeline из 4 последовательных трансформеров + финальный регрессор. Гарантирует отсутствие утечки данных, воспроизводимость и тестируемость.

6.1 Архитектура

TimeSeriesLoaderЗагрузка + индексация
→
AnomalyCleanerIQR-очистка давления
→
FeatureEngineerЛаги + скользящие + календарь
→
LGBMRegressorФинальная модель

6.2 Описание этапов

TimeSeriesLoader

Загрузка и объединение train/test в единый DataFrame. Преобразование date в DatetimeIndex с частотой 'D'. Заполнение пропусков через forward fill.

AnomalyCleaner

Обработка аномалий давления методом IQR. Значения meanpressure ~59 (при норме ~1000) заменяются медианой.

FeatureEngineer

Лаги: [1,2,3,4,5,6,7,14,21,28,30,60,90,180,365]. Скользящие: mean/std/min/max для окон 7/14/30/90 дней. Календарь: dayofweek, month, dayofyear, week, quarter, is_month_start, is_month_end. Первая разность для стационарности.

6.8 Общие выводы

Проведён комплексный анализ ВР среднесуточной температуры в Дели (2013–2017): полный цикл от EDA до production-пайплайна.

Сравнение 13 методов показало: LightGBM с грамотным feature engineering достигает лучшей точности (MAE = 1.13°C, −44.7% над бейзлайном). DL-методы уступают ML из-за малого объёма данных (~1500 точек). Статистические методы — сильный бейзлайн для структурированных сезонных рядов.

Анализ аномалий (IQR, Isolation Forest, DBSCAN) подтверждает: наилучший результат при консенсусном подходе (≥2 методов).

Ключевой вывод: эффективность прогнозирования определяется не только выбором модели, но и качеством подготовки данных, учётом сезонности и инженерией признаков.
